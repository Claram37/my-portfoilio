# Clara Kamande — Portfolio

Portfolio site for Clara Kamande, Product Designer in Nairobi. Built with React, React Router, Tailwind CSS and shadcn/ui. Every page is pre-rendered to static HTML.

| Command                        | What it does                                      |
| ------------------------------ | ------------------------------------------------- |
| `npm install`                  | Install dependencies                              |
| `npm run dev`                  | Start the dev server at `localhost:5173`          |
| `npm run build`                | Build the static site into `build/client/`        |
| `npm run preview`              | Preview the built site                            |
| `npm run typecheck`            | Check types                                       |
| `npx shadcn@latest add <name>` | Add a shadcn/ui component to `src/components/ui/` |
